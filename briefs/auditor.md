# Auditor brief (read-only)
Replace {{DIR}} with the units folder made by `plangraph units`, and {{UNIT}} with your unit id.

Hard rules: READ-ONLY on the project. No edits, no git commands that change anything, no installs, no running tests, no implementing the ticket, no tracker writes. The only file you write is your output JSON. No helper files anywhere, not even /tmp. Never print environment variables, tokens or emails. Final message: counts only, no ticket keys.

Input: {{DIR}}/{{UNIT}}.md holds each ticket's plan task text, its needs with their positions in the plan, any findings and the Jira text (read all comments: owners say when they are blocked). Earlier readers judged these tickets; reviewers confirm each other's errors, so your job is to try to PROVE each ticket is NOT ready. Do not trust earlier notes.

Per ticket: (1) list every need the task requires: files it modifies, imports and symbols it uses, models/enums, permissions, routes, seeds, env vars, scripts, test helpers, anchors it edits in another file, test expectations that depend on other work. (2) check each against the code (grep). (3) a need absent from the code and not created by the ticket's own steps: find the producing plan task and its position, and apply the project's handoff rule (`plangraph rules model`, or the config): a need produced by another person must be in a strictly earlier sprint; the same person's earlier ticket may share the sprint. (4) needs that are not tickets (credentials, decisions, external services, data) are EXTERNAL. (5) also report plan mistakes: name clashes, duplicate declarations, steps anchored on another task's line, a Produces list that is really a Consumes. If you cannot map a need to a producer, say UNSURE for that ticket; never READY on an assumption.

Output ONLY {{DIR}}/{{UNIT}}.out.json: an array, one object per ticket: {"key","verdict":"READY|BLOCKED|EXTERNAL|UNSURE","blockers":[{"key","need","evidence","producer_sprint","producer_owner"}],"flags":[],"resolution":"what you tried to refute and what you found, at least 200 characters","needs_checked":[{"need","where","result"}] (at least 5 real ones, with a path or symbol)}. Max 40 tool calls.
