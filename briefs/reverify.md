# Re-verifier brief (read-only)
Same hard rules as the auditor brief. Input: a first auditor's output file and the unit bundle. Re-verify ONLY (a) tickets judged BLOCKED, EXTERNAL or UNSURE, and (b) READY tickets whose resolution or flags admit something not verified (an assumption, "not read", "not traced", an unmapped need). For (a) try to REFUTE the block: is the cited need really absent from the code, does the producer really sit too late under the handoff rule, is it really another ticket's output and not this ticket's own step? For (b) finish the skipped check for real, with a path or symbol. Output ONLY {{DIR}}/{{UNIT}}.out-v.json: {"key","first_verdict","verdict","status":"CONFIRMED_BLOCK|BLOCK_REFUTED|CAVEAT_RESOLVED_READY|CAVEAT_FOUND_BLOCK|STILL_UNSURE|EXTERNAL","blockers":[...],"resolution":">= 250 characters","needs_checked":[...] (>= 4)}. Max 40 tool calls.
