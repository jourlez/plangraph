> **Amended 2026-11-25 by `2026-11-25-plangraph-0.3.0-revised.md`, which wins wherever the two disagree** (hard rename, no private-word secret, pull-request release flow, trimmed scope, deferred formatter and strict flags).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship plangraph 0.3.0 so that `KNOWN_ISSUES.md` lists nothing, every requirement of the owner's three playbooks is met or replaced by a named equivalent control that is actually in force, and the tracker provider and tenant alias are in place.

**Architecture:** Repository-wide mechanical work first (baseline tooling, formatter with a token-checked re-pin, strict flags, source checklist) so later tasks start from a clean, formatted tree; then parallel waves with exclusive file ownership for the known-issue fixes, the tracker provider and CI; then timing isolation, coverage, mutation and the final audit. Graph model v2 is a separate plan (`docs/superpowers/plans/2026-11-24-graph-model-v2.md`), written against the 0.3.0 outcome.

**Tech Stack:** TypeScript 7.0.2 (`tsc --noEmit`, Node's native type stripping), Node 24.15+ from Task 11 (24.2+ before it; decision D20) (`node:test`, `node:sqlite`), Biome 2.6.8, knip 6.48.0, lefthook 2.2.2, GitHub Actions; Python 3.10 to 3.14 with OR-Tools for the solver; ruff (through `uvx`, pinned `0.14.5`) shellcheck (`0.11.0` in CI, from its release tarball with a checked SHA-256) and actionlint (one version, chosen once at the start of Task 20: the latest release then, `1.7.12` or newer: 1.7.12 was already released when this plan was written; the controller records the version and its SHA-256 in the ledger, writes both in the workflow and updates this line; release tarball, checked SHA-256) in CI only. Zero runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-11-24-zero-gaps-design.md` (designs and decisions D1 to D22). Also implemented: `docs/superpowers/specs/2026-11-23-tracker-provider-design.md` (refreshed in the zero-gaps spec, section 13). Inputs: the playbooks `1-BULLETPROOF.md`, `2-MODERNIZE.md`, `3-AUDIT.md` (owner's local copies, not in the repository), the 0.2.0 SDD ledger and its audit summary.

Every snapshot tree passes the privacy scan, so the snapshot history holds only public-safe trees. The push runs `ci.yml` through its `push: branches: ['ci/**']` trigger (added in Task 2; before Task 2 merges no snapshot is pushed); record the run URL. `test/public-clean.test.ts` must pass on the tree first. ### Task 0: Accept the 0.2.4 hotfix (done): the solver fallback never runs a repository-chosen interpreter (K1, part 1, decision D22)

Done and published before this plan's 0.3.0 work. The private commit `abad83c` (`stop the solver fallback from running a repository-chosen interpreter`, parent `89193c9`) has the same tree as public `main` `da30467` (`release 0.2.4: ...`, parent `3790b69`); CI run 45354992186 on `da30467` is green on all 7 jobs, `mutation` included; the installed plugin is 0.2.4. `plan030` is rebased onto `abad83c`. No tag (D13).
